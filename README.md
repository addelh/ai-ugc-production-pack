# ai-ugc-production-pack

Research-aware Hermes skill for turning a plain-English ad concept into a full AI UGC production pack.

## What it includes
- `SKILL.md` — primary skill definition
- `templates/production-pack-template.md` — reusable output template

## Purpose
This skill is meant to be the source-controlled version of the AI UGC production pack workflow, so changes to prompting logic, structure, and templates are easy to review and evolve over time.
